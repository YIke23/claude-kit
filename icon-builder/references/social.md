# SNS・プラットフォームのアイコン

## 結論: 1024×1024の不透明PNG 1枚で全部賄える

```
サイズ    : 1024 × 1024 px
形式      : PNG（透過なし。背景を必ず不透明で塗る）
容量      : 1MB未満
カラー    : sRGB
```

**上限を決めているのはSlack**（プロフィール写真は512〜1024pxと明記されている唯一のサービス）。
**容量を決めているのはGitHub**（1MB未満）。この2つを満たせば残りは全部下回る。
`build_icons.py --targets social` がこの1枚を出し、1MBを超えたらJPG版も併せて出す。

## 各社の仕様（2026年8月時点、公式ヘルプ準拠）

| プラットフォーム | 推奨px | 最大容量 | 形式 | 表示形状 |
|---|---|---|---|---|
| X (Twitter) | 400×400 | 2MB | JPEG / GIF / PNG | 円（実UI） |
| Instagram | 公式非公開 | 未確認 | 未確認 | 円（実UI） |
| note | 330×330 | 10MB | JPG / PNG / GIF / HEIC | 円（実UI） |
| YouTube | 98×98以上（実務上800以上） | 15MB | JPG / GIF / BMP / PNG（**アニメGIF不可**） | 公式に「正方形または丸」 |
| LINE公式アカウント | 640×640 | 未確認 | 未確認 | 円（実UI） |
| Facebookページ | 公式非公開 | 未確認 | 未確認 | 円（実UI） |
| GitHub | 約500×500 | **1MB未満** | PNG / JPG / GIF | ユーザー=円 / **Organization=四角** |
| Slack プロフィール | 512〜1024 | 未確認 | 未確認 | 角丸四角 |

**WebPはどこも公式に対応を明記していない。** 使わない。
**透過の扱いも全社が未記載。** 白または黒に合成されるため、ライト/ダークで破綻する。必ず不透明で塗る。

## 円形クロップの安全域

円形表示されるサービスでは**四隅は必ず消える**。

- 絶対に安全: 中心から半径50%（1024pxなら中央の直径512px）の内側
- 実務上の推奨: 主要要素を**中央80%**（1024px中 819px四方）に収める
- 文字・ロゴタイプ: **中央70%**（約717px四方）以内

GitHub Organization と Slack は**四角**表示なので、
「円で切っても成立し、四角でも余白が不自然に見えない」中央寄せの構図が必要になる。

`verify_icons.py` は内接円からのはみ出しを画素で数えるので、目視で悩まなくてよい。

## 1枚で賄えないもの（別途作成）

これらは正方形ではないので、このスキルの守備範囲外。`web-image-builder` で作る。

| 用途 | 寸法 |
|---|---|
| X ヘッダー | 1500×500（上下60pxが環境により切れる） |
| note クリエイターページ ヘッダー | 1280×670（高精細なら1920×1006） |
| YouTube バナー | 2560×1440（セーフエリア 1235×338）、6MB以下 |
| LINE 背景画像 | 比率 2:1、10MB未満（2025年10月に8:5から変更） |
| Facebook カバー | 851×315、100KB未満推奨 |

## 運用上の注意

- **LINE公式アカウントのアイコン変更は1時間に1回まで。** 差し替えは一発で決める
- **YouTubeはアニメーションGIF不可。** 全社で動くアイコンに統一することはできない
- GitHubで1MBを超えるときだけ、JPG（品質85前後）か減色PNGを別途用意する
